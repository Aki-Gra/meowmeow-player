# MeowMeow Music Player 1.0.2 — Beta 1 🐱

**First shareable, permanently signed Android preview release.**

MeowMeow Music Player is an offline, folder-based MP3/MP4 audio player for **Android 8.0 or later**. The APK is intended for personal installation and testing, not Google Play.

## What's included

- Pink cat-and-vinyl MeowMeow launcher icon.
- Select music folders through Android's file picker; keep multiple favourite folders.
- Play MP3 audio and compatible MP4 audio tracks without copying your files.
- Play/pause, seek, skip, shuffle and Repeat Off/All/One.
- Restore the last song and position **paused** when reopening the app.
- Attempt to skip unreadable tracks, show a message and avoid endless error retries.
- Audio equaliser with presets and manual bands on compatible phones.
- Background playback with Android media notification and standard system controls.
- Connection retry, missing-folder permission recovery and automated playlist-decision tests.

## Install

1. Under **Assets** below, download **`MeowMeowMusicPlayer-v1.0.2-beta.1.apk`** to your Android phone.
2. Open the APK in your phone's Downloads/Files app. If Android prompts you to allow installation from that source, enable it for your trusted file manager/browser.
3. Launch **MeowMeow Music Player** and select your music folder. The app reads your files in place.

**Important for existing testers:** Earlier GitHub Actions **debug** APKs used a different signing certificate. Android may refuse to update them in place. If required, note your folder selections and preferences, uninstall the previous debug APK, and then install this signed preview. Uninstalling clears app-specific settings, but music files stored outside the app are unaffected.

**Future updates:** New signed versions using this same permanent signing certificate and a higher version code can be installed over this signed release without uninstalling.

## Preview limitations

- **Beta / device testing in progress.** Real-world background playback, Bluetooth/lock-screen media controls, corrupted-file recovery, various Android versions and cloud-backed folders still need wider testing.
- Only MP3/MP4 files directly inside chosen folders are scanned; subfolders are not included. MP4 video is not displayed; supported audio codecs depend on the phone.
- No built-in automatic updater. Future APK versions are installed manually.
- Signing keys are private; only the signed APK is attached. This is **not** a Google Play release.
- No open-source licence has been assigned to the project.

Please report problems through the repository's **Issues** tab, including the Android version and steps to reproduce, without posting private files or passwords.
